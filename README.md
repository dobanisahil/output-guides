# The Output Guides — deployment (2 minutes, free)

This is a static site — no build step, no server, nothing to pay for.

## Go live on GitHub Pages (free)

1. Create a free GitHub account if you don't have one: https://github.com/signup
2. Create a new repository (e.g. `output-guides`), public, no README/license needed.
3. Upload every file in this folder to that repository, keeping the `articles/` folder structure intact (drag-and-drop upload on github.com works fine, or use `git push` from the desktop app if it's linked).
4. In the repo: Settings → Pages → Source → "Deploy from a branch" → branch `main`, folder `/ (root)` → Save.
5. GitHub gives you a live URL, usually `https://YOUR-USERNAME.github.io/output-guides/` within a minute or two.

Once it's live, tell me the URL and I'll:
- Replace the placeholder domain in `sitemap.xml` and `robots.txt` with your real one
- Submit the sitemap to Google Search Console (needs a quick free Google account verification from you — one-time, no payment)
- Keep publishing new articles to grow the catalog
